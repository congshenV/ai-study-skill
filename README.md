# AI Study Skill 🎓

一套基于 AI 的完整学习系统，作为 [Claude Code](https://claude.ai/code) 的 Skill 运行。

通过交互式流程创建个性化学习计划，并以连贯的引导式体验驱动每日学习。

## ✨ 核心能力

| 能力 | 说明 |
|------|------|
| **学习阶梯** | 把任何技能拆成 5 个等级，从新手到独立做项目 |
| **智能资源筛选** | 网络搜索 + 用户自有资源整合，支持视频/书籍/GitHub/论文等 |
| **20 小时学习计划** | 找出最重要的 20% 内容，设计 10 次 × 2 小时学习计划 |
| **费曼学习法** | AI 用大白话讲 → 你讲回来 → AI 纠错（对/漏/混淆/假懂）|
| **AI 考官** | 固定题数覆盖知识点，打分 + 分析薄弱点 + 阶梯定位 |
| **速查表自动生成** | 按主题归类，2-4 张，学完即可带入实践 |
| **中断恢复** | 随时中断，下次自动回到上次进度 |
| **校准点机制** | 第 3/7 课后自动评估，动态调整后续计划 |

## 🚀 使用方式

### 安装

将本仓库克隆到 Claude Code 的 skills 目录：

```bash
git clone https://github.com/congshenV/ai-study-skill.git ~/.claude/skills/study
```

### 指令

| 指令 | 用途 |
|------|------|
| `/study <技能名>` | 创建学习计划（交互式 4 步确认） |
| `/study <技能名> today` | 开始/恢复今天的学习 |
| `/study status` | 查看学习进度 |
| `/study list` | 列出所有学习计划 |
| `/study <技能名> complete` | 10 课完成后生成最终速查表 |

### 每日学习流程

```
/study python today
    │
    ▼ 自动打开资源 + 可选计时
📖 学习资源（30-40 分钟）
    │
    ▼ 自动过渡
🧠 费曼学习法（20-30 分钟）
    │  逐个知识点：AI讲 → 你讲 → 纠错
    │
    ▼ 自动过渡
✍️ 三层练习（30-40 分钟）
    │  概念 → 动手 → 场景
    │
    ▼ 自动过渡
📝 AI 考官（15-20 分钟）
    │  固定题数，覆盖全部知识点
    │
    ▼ 自动过渡
📋 复盘 + 速查表更新（5-10 分钟）
```

## 📖 方法论

本系统基于以下六个学习方法的有机整合：

1. **学习阶梯** — 看清整张地图
2. **资源筛选** — 从噪音里找信号
3. **20 小时学习法（二八法则）** — 聚焦最重要的 20%
4. **费曼学习法** — 逼自己讲明白，暴露假理解
5. **AI 考官** — 测试真实水平
6. **速查表** — 压缩成可带入实践的外部记忆

**完整闭环：路径 → 筛选 → 聚焦 → 理解 → 测试 → 压缩 → 实践**
